# OpenOcta Skill 模版

本目录是新建 OpenOcta 技能的起点。请 **整体复制** 本目录后改名为你的技能目录（例如 `my_skill`），再逐项替换占位内容。

## 目录结构

| 路径 | 说明 |
|------|------|
| `SKILL.md` | **必填**。Agent 读取的主技能说明：何时启用、分步指令、注意事项。 |
| `README.md` | **建议**。给人看的说明：功能概述、使用示例、依赖、更新日志。 |
| `mate.json` | **建议**。机器可读元数据；合并入主仓库时请填写 **author**（作者）、**affiliation**（所属单位/团队或个人），便于致谢与索引。 |
| `references/` | **可选**。长篇参考文档，由 `SKILL.md` 引用路径提示 Agent 按需读取。 |
| `scripts/` | **可选**。可执行的辅助脚本（请写明运行环境与参数）。 |

## 编写要点

1. **`SKILL.md` 开头**：使用 YAML frontmatter 提供 `name` 与 `description`（或遵循 OpenOcta 平台当前要求的字段），保持 `description` 能概括「何时应加载本技能」。
2. **步骤清晰**：优先使用有序列表描述操作流程；涉及危险操作（删除数据、生产变更等）必须写明确认项或禁区。
3. **边界明确**：写清楚本技能**不负责**什么，避免与其它技能职责重叠时产生歧义。
4. **`mate.json`**：与 `SKILL.md` 中的 `name` 保持一致；**务必填写 `author` 与 `affiliation`**。

完成后可在仓库根目录执行：

```bash
./build_zip.sh <你的技能目录名>
```

生成 `dist/<目录名>.zip` 用于分发或自检。
